# Zpercord

Chat app with servers, channels, roles and **Zpercord Pro**. Blue theme with a dark blue background.
It's all in a single file: open `index.html` in any browser. Data is saved in the browser itself (localStorage).

- **Servers**: create them (with templates), join with an invite, explore public ones, server boosts with levels 1–3.
- **Channels**: text, voice and announcement channels, categories, private channels by role, edit/delete.
- **Roles**: colors, permissions (admin, manage channels, kick…), separate display, ordering, "view as role".
- **Chat**: Markdown, @mentions, replies, editing, reactions, pins, search, files, emojis, `/ayuda` bot.
- **Pro**: animated avatar, profile themes, 500 MB uploads, 4000 characters, emojis across servers, super reactions, 4K streaming, 2 boosts, Pro gifts (demo, no real payments).
