# ZperCraft — an original voxel sandbox for Android

Explore an endless procedurally generated block world, mine and gather, craft tools and buildings,
survive the night against original creatures — or switch to Creative and build freely.

Everything is original and generated by code at runtime: terrain, the 16×16 block textures (painted
into a texture atlas at start-up), item icons, creature models, sound effects and the ambient music.
There are no external art or audio assets. The game is written in **TypeScript + three.js (WebGL2)**
and packaged for Android with **Capacitor**.

## Run / build

```bash
cd voxel
npm install
npm run dev          # desktop browser (WASD + mouse; touch controls appear automatically on touch devices)
npm run build        # type-check + production bundle in dist/
npm run build:html   # single standalone file: dist/zpercraft.html (a copy is kept in release/zpercraft.html)
```

### Android APK

* **CI (recommended):** pushing changes under `voxel/` runs `.github/workflows/voxel-android.yml`, which builds
  `app-debug.apk` and uploads it as the `zpercraft-debug-apk` artifact.
* **Locally:** Android Studio (SDK 34, JDK 17), then `npm run android:sync && npm run android:open` and press *Run*
  (or `cd android && ./gradlew assembleDebug`).

The native project (`android/`, package `com.zpercraft.game`) is landscape-only, immersive full-screen,
keeps the screen on, hardware accelerated, requires OpenGL ES 3, and maps the Android Back button to pause/close.

## Gameplay

* **World:** infinite-style chunk world (16×16×128) generated from a seed — the same seed always gives the same world.
  Biomes: Meadows, Ashwood Forest, Dunes (desert), Highlands (mountains with snow caps), Frostlands, Ocean,
  Shoreline, River valleys, and offshore Isles. Spaghetti tunnels and large caverns, magma pools deep underground,
  six ore types (Coal, Copper, Iron, Sunstone, Azurite, Glowshard), glowing Glowcap mushrooms in caves,
  four tree species, flowers, berry bushes, spineplants and dry shrubs.
* **Blocks:** 60+ blocks with their own textures, hardness, tool type, harvest tier, material sounds, collision
  shapes and placement rules (plants need soil, torches need a supporting face, doors need two free blocks, etc.).
* **Survival:** health, hunger/saturation, regeneration, starvation, fall damage, drowning (air bubbles),
  magma and spineplant damage, darkness spawns, death with dropped belongings and respawn.
* **Progression:** punch wood → boards & sticks → Workbench → wooden tools → stone tools → Kiln (smelting) →
  copper → iron → azure gear. Tool tiers gate which ores drop, tools wear out (durability bar).
* **Crafting:** recipe-list crafting with three stations — by hand, at a Workbench, at a Kiln (needs fuel).
  65 recipes: tools, blades, tillers, torches, crates, doors, lamps, building blocks, dyed cloth, glass, ingots,
  food (roast haunch, trail bread, glowcap stew), buckets.
* **Interaction:** trees can be felled; saplings regrow trees; water flows and drains (buckets pick up/pour);
  doors open/close; storage crates keep items (saved with the world); torches, lamps and glowcaps light caves;
  tilled soil + grain seeds grow crops over time; berry bushes regrow.
* **Creatures (all original):** *Mossback* (shelled grazer, follows berries, eats grass), *Hopkin* (skittish hopper —
  sneak to approach), *Glimmerwing* (glowing night moth), *Gloomling* (one-eyed night stalker that retreats from
  sunlight), *Crag Crawler* (six-legged cave dweller), *Stingwisp* (diving night flier). AI states: wander, idle,
  follow lure, flee, seek food, chase/attack, circle-and-dive, fade.
* **Creative mode:** flight (double-tap jump), instant breaking, full item catalog, time-of-day slider,
  weather (clear/rain/storm), creature summoning, world rules (daylight/weather cycle, spawning, keep inventory,
  difficulty), set spawn, switch game mode.
* **Saving:** multiple worlds stored locally (IndexedDB in the app's private storage): create (name, seed, mode,
  difficulty), continue, rename, delete. Only modified chunks are stored (run-length compressed). Autosave every
  30 s and when the app is paused/backgrounded.

## Expansion: dimensions, caves, ores and more

* **Dimensions:** craft a **Sky Rift** (frostquartz + glow dust + prism shards) or an **Ember Rift** (rubellite + slate + coal)
  at a Workbench, place it and *Use* it. **Celestia** is a realm of floating islands, cloud banks, silverleaf trees, Starstone
  and peaceful Cloudrays (fall off an island and you drop back home). The **Ashen Wastes** is a volcanic land of basalt spires,
  ash plains, magma seas, ember trees, Emberite and hostile Cinderhounds. A return rift is placed when you arrive.
* **Cave zones:** glowing moss grottos (moss, mud, hanging glow vines, glowcaps), prism crystal caverns (crystal blocks and
  shard clusters), frost caves under the Frostlands and basalt in the deep layers.
* **New ores:** Frostquartz (high mountains), Rubellite (very deep), Starstone (Celestia), Emberite (Ashen Wastes) — plus
  storage blocks for each and a new top tool tier (Emberite).
* **Combat & survival:** armour sets (copper, iron, azure, emberite — 4 slots each, damage reduction), Shortbow + arrows,
  Blast Kegs (chain-reacting explosives), fishing with a Fishing Line, bedrolls (sleep through the night, set spawn),
  new food (fish, ashfruit, ember pie).
* **Building:** ladders (climbable), slabs, steps, fence posts, lanterns, bookshelves, rugs, gem blocks.

## Controls

* **Touch:** floating joystick (left side; push to the edge to sprint), drag anywhere else to look,
  **tap** to place/use, **press and hold** to break (or use the BREAK button), JUMP, SNEAK (toggle), PLACE,
  context-sensitive USE button (Open / Craft / Kiln / Harvest / Till / Plant / Eat / Fill / Pour / Attack),
  sprint toggle, drop (hold to drop the stack), camera view, fly (creative). Hotbar taps select items; ⋯ opens the pack.
  *Settings → Touch → Edit layout* lets you drag and resize every button; size, opacity, left-handed mode, haptics,
  tap/hold behaviour and crosshair-vs-touch-point aiming are configurable.
* **Gamepad:** left stick move, right stick look, A jump, B sneak, RT break, LT place, X use, Y inventory,
  LB/RB hotbar, Start pause, D-pad up fly.
* **Keyboard/mouse:** WASD, mouse look, LMB break/attack, RMB place, MMB/F use, Space jump (double-tap to fly),
  Shift sneak, Ctrl sprint, E inventory, Q drop (Ctrl+Q stack), V camera, 1–9 hotbar, C world options, Esc pause.

## Architecture (`src/`)

| Module | Responsibility |
| --- | --- |
| `world/Blocks.ts` | Block registry (shapes, render groups, hardness, tools, light, textures, collision/pick boxes), lookup tables |
| `world/Noise.ts`, `world/Generator.ts` | Seeded simplex noise; terrain, biomes, rivers, islands, caves (interpolated 3D noise), ores, trees |
| `world/Mesher.ts`, `world/worker.ts` | Worker-side lighting (sky + block light flood fill across a 3×3 chunk region), face-culled meshing with ambient occlusion & smooth lighting, 2×-downsampled LOD meshes, per-section visibility graphs |
| `world/World.ts` | Chunk streaming/unloading, worker pool, editing, fluids, growth ticks, support rules, crates, persistence, portal occlusion culling |
| `gfx/` | Procedural texture atlas, chunk/water materials (light injection, sky-matched fog, reflective animated water), sky dome + clouds + sun/moon rig, pooled particles & weather |
| `game/` | Items & icons, inventory & crafting, player controller, physics, creatures (models + AI), dropped items |
| `core/` | Game loop & session lifecycle, interaction, settings & presets, unified input (touch/keyboard/gamepad) |
| `ui/` | Menus, HUD, inventory/crafting/crates, settings, world options, touch controls + layout editor |
| `audio/` | Synthesized material sounds, creature voices, ambience and generative music |
| `save/` | IndexedDB world store with RLE chunk compression |

### Performance

* Terrain generation, lighting and meshing run in a pool of Web Workers; the main thread only uploads geometry.
* Chunk sections (16³) are separate meshes for frustum culling plus **occlusion culling** through precomputed
  section connectivity (caves are skipped when you are on the surface and vice-versa).
* **LOD:** chunks beyond the full-detail distance are meshed at half resolution without AO or plants.
* Hidden faces are culled, vertex attributes are packed (Int8 normals, Uint8 colours/light, Uint16 indices when possible),
  one mip-safe padded texture atlas serves every block, particles are a single instanced draw call from a pool,
  dropped-item meshes are pooled, far creatures update at a reduced rate.
* Chunks outside the render distance are unloaded (saved first if modified) and their GPU buffers disposed.
* Presets **LOW / MEDIUM / HIGH / ULTRA** (render distance, LOD distance, shadows, leaves, clouds, particles,
  resolution) with automatic device-based default, plus dynamic resolution ("performance mode") and a 30/60 FPS target.

## Honest status

* The APK could not be compiled inside the development sandbox (Google's Android repositories are not reachable
  there); the project is validated by TypeScript type-checking, a production build, `cap sync`, and headless-Chromium
  play tests (world generation, breaking/placing, crafting, crates, water flow/drain, crops, torches, creature AI and
  combat, touch controls, save → quit → reload persistence). The CI workflow produces the APK.
* Frame rates were not measured on physical Android hardware; tune with *Settings → Graphics* (Show FPS, presets).
* Dropped items and creatures are not saved when you quit (creatures respawn naturally).
