# iSuit

Launcher para Android estilo "teléfono de videojuego", con diseño propio.

- Fondo verde de iSuit (mantén presionada la hora para usar tu propio fondo de pantalla).
- Botón **📱 Mis apps / 🎮 iSuit**: cambia entre las apps propias de iSuit (salen primero) y tus apps instaladas.
- Hora arriba a la izquierda, batería a la derecha y tarjeta **Hoy** (fecha, próxima alarma, app favorita).
- **Íconos redondos** en cuadrícula de 4; la app elegida tiene un aro blanco y su nombre aparece abajo.
- **Botones de volumen**: subir/bajar = moverte entre apps · **mantener** = abrir.
- Las apps que más usas salen primero.
- El "teléfono" sube deslizándose cada vez que vuelves al inicio.
- Mantén pulsada una app: información o desinstalar.

## Apps propias de iSuit
- **💪 Pulso** (fitness): pasos de hoy con anillo de meta, km, calorías, racha y entrenamiento rápido de 7 minutos.
- **💬 Charla** (mensajes): tus apps de chat en un lugar + escribir a un número por SMS o WhatsApp sin guardar el contacto.
- **🚗 AutoID** (identificador de carros): toma o elige una foto y Gemini (Google AI Studio, gratis) te dice marca, modelo, años, tipo, motor y un dato curioso. La API key se pega dentro de AutoID.
